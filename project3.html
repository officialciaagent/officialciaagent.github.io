Arcade Shooter


Arcade Shooter is an interactive game developed using Web VPython that challenges players to control a moving shooter and eliminate dynamically moving targets within a constrained space. The player navigates the shooter using keyboard controls and fires projectiles in four directions, with a limited ammunition system that requires reloading. The objective is to hit as many moving targets as possible while managing shot efficiency and timing.

The project incorporates real-time simulation, collision detection, and score tracking to create an engaging gameplay experience. A custom collision detection function was implemented to determine when bullets intersect with targets, triggering score updates and removing objects from the scene. The game also includes a scoring system that rewards accuracy and penalizes excessive shooting and time taken, encouraging players to optimize their strategy.

Through this project, I gained experience with managing dynamic object lists and implementing game logic that balances user input, physics, and scoring systems. Arcade Shooter demonstrates my ability to design interactive applications that combine real-time updates, user control, and performance-based feedback.
