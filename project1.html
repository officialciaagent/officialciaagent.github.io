Escape the Maze


Escape the Maze is an interactive 2D game developed using Web VPython that challenges players to navigate a maze while avoiding collisions and strategically removing obstacles. The player controls a movable sphere using keyboard inputs (WASD keys) and must guide it to the end of the maze without hitting any walls. To increase interactivity and complexity, the game includes breakable barriers that rotate continuously and can be destroyed using directional projectiles fired with arrow keys.

The project demonstrates core programming concepts such as event-driven input handling, collision detection, and real-time simulation. A custom collision detection function was implemented to manage interactions between the player, walls, and bullets. The game loop continuously updates object positions and checks for collisions, ensuring smooth gameplay and responsive controls.

Through this project, I developed experience with vector-based movement, object-oriented design, and managing dynamic game states. Escape the Maze highlights my ability to combine logic, user interaction, and visual elements to create an engaging and functional application.
